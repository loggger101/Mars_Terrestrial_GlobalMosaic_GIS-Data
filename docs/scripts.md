# The build scripts

All 108 scripts in `Mars Remote Sensing Project/build/`, grouped by what they make. The description is each script's own docstring. **Python** says which interpreter it needs: *ArcGIS* (arcpy or GDAL: `C:\Program Files\ArcGIS\Pro\bin\Python\envs\arcgispro-py3\python.exe`), *system* (python-pptx), or *either*; the three `.ps1` renderers need PowerShell and Microsoft Office. Generated by `github_sync.py`; don't edit it here.
