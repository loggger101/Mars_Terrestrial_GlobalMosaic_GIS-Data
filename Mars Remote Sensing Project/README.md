# Mars Remote Sensing Project

The written side of the project: what was handed in, the record every number is checked
against, and the scripts that made everything. The data side (the ArcGIS Pro project, its
layers and layouts) is in [`../Mars Project/`](../Mars%20Project).

| Folder or file | What it holds |
|---|---|
| [`Deliverables/`](Deliverables) | the final paper and deck, and the interim report and presentation |
| [`Earlier deliverables/`](Earlier%20deliverables) | the prospectus and Presentation 1, as handed in |
| [`PROJECT-KNOWLEDGE.md`](PROJECT-KNOWLEDGE.md) | the knowledge base: every result, how it was reached and the traps met on the way, by numbered section; the paper's source cites a section beside every number |
| [`build/`](build) | 274 build scripts: every raster product, figure, map layout, audit and deliverable, and `logs/`, the run logs and scores the charts are drawn from |
| [`NEXT-STEPS.md`](NEXT-STEPS.md) | the working plan and the table of decisions, each with the date it was answered |
| [`HANDOFF-DESKTOP.md`](HANDOFF-DESKTOP.md) | how to work on the project on each machine |
| [`INTERIM-PLAN.md`](INTERIM-PLAN.md) | the plan the interim was built to |

The last three are working notes, written to the next session rather than to a reader.
